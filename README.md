# SAP-Design-Handoff

Public handoff package for the Claude Design / Grok Build bake-off.

## Source of truth
- **Rosetta Stone:** `rosetta-stone.md` in this repo — a pointer to the latest stone in DaveCC2/Peters-Brain. Load it. Do not version-pin it here. Currently tracking v1.5.
- **Build manifest:** `build-manifest-v1.md` — the page spec. Load it first, then the stone.
- **Visual directions:** [`visual-directions/`](visual-directions/) — fifteen full briefs plus a shared copy lock. This is the bake-off.

If the manifest and the stone conflict, the stone wins. Update the manifest, not the stone. If a brief and `visual-directions/_shared.md` conflict, `_shared.md` wins. Public page copy is locked in `_shared.md` even when the stone's elevator pitch still carries a contrast clause.

## Assets (in-repo)
- `companies/podcast/assets/logos/` — four logo JPEGs. Design decides which mark to place.
- `companies/podcast/assets/headshots/Dave Headshots/` — 13 frames.
- `companies/podcast/assets/headshots/Jerremy Headshots/` — 20 frames.

Do not invent logos, colors, or faces. Do not pick a single "official" headshot unless Dave names one.

## For the design tools
1. Load `build-manifest-v1.md`, then `rosetta-stone.md`, then `visual-directions/_shared.md`.
2. Execute **one** numbered brief from `visual-directions/`. Do not blend briefs. Do not invent a sixteenth.
3. One Subscribe button above the fold. No email in the hero.
4. Hard fail any treatment that contrasts service against ordinary work, or that uses a rejected tagline. The politician line is tone, not slogan. Read the hard-fail list in `_shared.md`.
5. If a visual fights the sentence, the sentence wins.
6. Phone first. Jill. Jerremy (two r's). AI proposes; Dave decides.
