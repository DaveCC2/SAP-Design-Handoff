# SAP-Design-Handoff

Public handoff package for the Claude Design / Grok Build bake-off.

## Source of truth
- **Rosetta Stone:** `rosetta-stone.md` in this repo — a pointer to the latest stone in DaveCC2/Peters-Brain. Load it. Do not version-pin it here.
- **Build manifest:** `build-manifest-v1.md` — the page spec. Load it first, then the stone.

If the manifest and the stone conflict, the stone wins. Update the manifest, not the stone.

## Assets (in-repo)
- `companies/podcast/assets/logos/` — four logo JPEGs. Design decides which mark to place.
- `companies/podcast/assets/headshots/Dave Headshots/` — 13 frames.
- `companies/podcast/assets/headshots/Jerremy Headshots/` — 20 frames.

Do not invent logos, colors, or faces. Do not pick a single "official" headshot unless Dave names one.

## For the design tools
1. Load `build-manifest-v1.md`, then `rosetta-stone.md`.
2. Generate 15 visual directions. No production code.
3. One Subscribe button above the fold. No email in the hero.
4. Hard fail any treatment using "Service over career," "Where Service Beats Career," or any line that throws shade on people with jobs. The politician line is tone, not slogan.
5. If a visual fights the sentence, the sentence wins.
