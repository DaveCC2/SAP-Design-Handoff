# 09 · 1i — The Question

## Feeling

Asked, not told. The one direction that opens by wondering aloud instead of declaring — the opposite of a lecture, which is what the anti-avatar walks away from.

## Layout logic

Inverted hierarchy: the question is the display object, the sentence sits below a rule as the answer, paired with the button. Reading order is question → answer → act.

## Key visual choice

A high-contrast display serif at three and a half times body size, so scale carries the idea and no image is needed.

## Spec


Highest ceiling if the question is right. Blocked on copy approval.
