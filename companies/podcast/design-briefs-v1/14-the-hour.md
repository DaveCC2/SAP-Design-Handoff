# 14 · 1n — The Hour

## Feeling

Honest about the cost. It names the hour it wants instead of pretending the ask is free — the only direction that negotiates with the calendar.

## Layout logic

One narrow centred measure with unusually generous air, and a measuring rule holding the base of the fold. Vertical rhythm reads as duration: sentence, ask, then how long it takes.

## Key visual choice

A sixty-minute scale drawn as the closing element. A ruler is the entire graphic language, which turns the biggest objection — no time for noise — into the page's own promise.
