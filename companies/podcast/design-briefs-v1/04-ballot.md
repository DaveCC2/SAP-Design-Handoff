# 04 · 1d — Ballot

## Feeling

A civic object you hold, not a brand that talks at you. Plain, procedural, faintly consequential — participation as paperwork you actually want to do.

## Layout logic

A single sheet centred on a desk-toned ground. Ruled bands stack the content the way a form stacks fields, so the ask reads as the one line you complete.

## Key visual choice

The button is a filled ballot oval. Subscribing is drawn as casting one mark — deliberately generic civic stationery, no seal, no eagle, no borrowed officialdom.

## Honest risk

Most on-theme with the movement. Watch the line between civic and governmental — do not add a seal.
